## 数据与架构变更

- **新表**：`decisions`（决策日志）、`meetings`（会议+行动项 JSON）、`contacts`（干系人）；tasks 新列 `start_date`、`is_milestone`（ensure_column 自动迁移，老库无损升级）。
- **备份兼容**：JSON 备份/导入（v5）包含三张新表；旧版本备份导入自动补空。
- **新命令**：决策/会议/干系人 CRUD、`xlsx_sheets`/`xlsx_read`（calamine）、`export_xlsx`（rust_xlsxwriter）、`export_project_md`、`taskbar_progress`、`notify_desktop`、`autostart_set/status`、`set_quick_hotkey`、`quick_hide`、`save_binary_file`（甘特 PNG）。
- **新依赖**：tauri-plugin-global-shortcut / autostart / single-instance / deep-link、calamine 0.36（dates feature）、rust_xlsxwriter 0.99（chrono feature）。
- **测试**：新增 `xlsx_roundtrip_dates_and_merged_cells`（写→读合并单元格填充+日期转换）与 `export_xlsx_writes_readable_file`，`cargo test` 11 通过。

## 修复的坑（走查中发现）

1. 列映射「阶段列」模式下父任务 id 回填丢失 → persistTask 返回值统一捕获。
2. 干系人跟进天数语义颠倒（已逾期显示成"还有 N 天"）→ `周期 - 距上次沟通` 语义修正。
3. init 中误删 `bindEvents()` 调用导致视图切换失效。
4. switchTab 不刷新 header，从干系人切时间线标题残留。

## 遵循「明确不做」

LiquidPlanner 全量排期、PERT/关键路径、交互式 Toast 按钮、前台窗口自动追踪、Jump List/徽标、剪贴板后台监听（以「📌 从剪贴板建任务」命令替代）、实时 MD 双写、CFD 累积流图、.mpp 导入、多 sheet 关联解析、依赖连线/自动重排——全部未做。
