# PM 工具功能调研与选型（2026-09）

> 目的：调研主流项目管理 / 待办工具的功能，结合本项目「本地优先、单人使用、多项目并行的项目经理」定位，挑出投入产出比最高的功能落地。

## 一、调研对象与亮点功能

| 工具 | 定位 | 对个人 PM 最有参考价值的功能 |
|---|---|---|
| Microsoft To Do / Any.do | 个人待办 | **「我的一天 / My Day」**：每天一个跨清单（跨项目）聚焦视图，自动带出今日到期与逾期任务 |
| Todoist / TickTick | 个人待办 | 自然语言快速输入（本项目已有）；**日历视图**看截止日分布；重复任务支持每日/每周/每月 |
| Asana | 团队协作 | 任务依赖、时间线、**按最后活动时间筛选**（GTD 每周回顾的基础） |
| Jira | 研发管理 | **看板 WIP 限制**（在制品超限即暴露瓶颈）、问题链接（阻塞/被阻塞）、自动化规则 |
| Linear | 研发管理 | **命令面板（Ctrl+K）** 跨项目极速跳转，键盘流操作 |
| Trello | 轻量看板 | 标签、卡片老化提示；依赖与 WIP 需插件，原生较弱 |
| GTD 方法论 | 方法 | **每周回顾（Weekly Review）**：清理停滞任务、升级等待项 |

来源：Zapier《7 best to do list apps》、Atlassian《Working with WIP limits for kanban》、Asana GTD 指南及 Asana/Jira 社区关于「自动归档停滞任务」的讨论等（2025~2026 年评测与官方文档）。

## 二、与本项目现状的差距分析

本项目已具备：多项目管理、列表/看板/统计、自然语言快速添加（日期/@负责人/!优先级/#风险/#每日）、每日循环任务、检查清单、日报/周报、自动备份、托盘常驻。

缺口（按「每天都会疼」的程度排序）：

1. **看不到全局**：盯 5 个项目就要点 5 次，才能知道今天总共有哪些事到期 —— 对多项目 PM 是最大痛点。对应主流方案的正是 My Day / 今日聚焦。
2. **重复任务只有每日**：周会、周报、月度盘点这类 PM 高频节奏性任务无法表达，只能靠手动改日期。
3. **僵尸任务没有出口**：做了很久的任务停在那里没人发现，等周报时才想起。主流工具靠「按最后活动时间筛选」+ 每周回顾解决，本项目连更新时间都没记录。
4. **进行中任务无限堆积**：看板「进行中」列没有 WIP 概念，容易什么都开一半。
5. **截止日分布不直观**：列表按时间分组了，但没有月历视角看「哪几天扎堆」。
6. **切项目靠鼠标**：没有跨项目搜索 / 键盘直达。

## 三、选型结论（本次落地）

| 采纳功能 | 来源参考 | 理由 |
|---|---|---|
| ✅ 今日聚焦（跨项目今日+逾期+进行中，按项目分组，一键复制今日清单） | MS To Do「我的一天」 | 单人多项目场景收益最大，直接改变每天开工方式 |
| ✅ 重复任务扩展：每周 / 每月（`#每周` `#每月`，完成后自动推期） | Todoist / TickTick | PM 的周会/周报/月盘是刚需，改动小 |
| ✅ 停滞任务检测（记录更新时间，>7 天未动打 💤 标，统计页出清单） | Asana 按活动时间筛选 + GTD 周回顾 | 给周报和周回顾提供「该清理/升级谁」的清单 |
| ✅ 看板 WIP 超限提醒（进行中 >5 亮黄） | Jira kanban WIP limit | 几行代码换来流程纪律 |
| ✅ 日历视图（当前项目月历，看截止日扎堆） | Todoist / TickTick | 与列表/看板互补的第三种时间视角 |
| ✅ Ctrl+K 命令面板（跨项目搜项目/任务，回车直达） | Linear | 键盘流切换项目，多项目越多收益越大 |
| ✅ 每日定时提醒（如 09:30 通知今日到期数，可配置） | 系统级提醒通用实践 | 把「打开软件看」变成「软件推给你」 |

## 四、明确不做（及原因）

- **任务依赖（阻塞/被阻塞）**：单人本地工具收益低、UI 复杂度高；现有「等人/等外部」状态 + 备注已覆盖大部分场景。等真实需要再上。
- **甘特图 / 时间线**：需要起止日期与工期模型，和当前「待办粒度」不匹配。
- **多人协作 / 账号**：本地优先是产品定位，引入协作会连带要做同步、冲突、权限。
- **番茄钟 / 时间统计**：与「盯进度、发报告」的主工作流关系弱。

## 五、落地清单

- 后端（Rust/SQLite）：`tasks.updated_at` 字段（每次保存自动刷新）、每周/每月重复的推期规则、每日定时提醒线程（时间可配置，存 meta）。
- 前端（原生 HTML/JS）：侧栏「今日聚焦」入口、日历视图、Ctrl+K 面板、重复任务选择器、停滞标记与统计面板、WIP 提醒、复制今日清单。
