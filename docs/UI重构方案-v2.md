# PM 待办助手 v2.0 —— 信息架构与交互重构方案

## 一、现状问题诊断

v1.2 → v1.5 三轮功能叠加后，界面呈现五类「堆积病」：

1. **侧栏分组语义混乱**：「需求池」悬挂在「智能视图」分组标签下；「组织记忆」名称抽象；页脚塞了 8 个图标按钮（主题/提醒/设置/回收站/备份/导入/CSV/Excel），难以辨认且全局/项目级操作混在一起。
2. **顶栏 7 个平铺 Tab 两种性质混排**：列表/看板/日历/时间线是「任务的四张面孔」（同一数据的呈现方式），统计/决策/档案是「项目的三个独立页面」，排成一排导致认知过载。
3. **设置单长弹窗**：自动化、收尾时间、桌面集成、AI 供应商挤在一个滚动弹窗里，无导航；而数据类操作（备份/导入）又散落在侧栏页脚，遥相呼应但不成体系。
4. **快捷键错位**：README 宣称 1-7 按视图顺序切换，代码实际是 1=列表 2=看板 3=统计 4=日历 5=时间线，与界面顺序不一致。
5. **项目级工具入口分散**：Excel 导入/导出、CSV、Markdown 导出、另存为模板散落在页脚图标和项目设置弹窗底部，无统一「项目工具」入口。

## 二、新信息架构（IA v2）

**原则：全部功能保留，只重组入口；数据模型与后端零改动。**

### 2.1 侧栏（自上而下）

```
[✔] PM 待办助手 v2.0
────────────────────────
📅 今日聚焦        8     ← 跨项目驾驶舱
📥 收件箱          3     ← 分拣入口
────────────────────────
项目            [＋]
  · 闸机二期       12
  · 示例项目        4
  ▸ 已归档 (2)
────────────────────────
洞察            [＋]
  🎯 智能视图（含 🧹 待清理）
  💡 需求池
────────────────────────
记录
  🗂 会议纪要
  👥 干系人
  📝 每日笔记
────────────────────────
[🌙] [⏰] [🗑3] [⚙]           ← 仅 4 个高频按钮
数据存于本机 SQLite · 每日自动备份
N 新建 · 1-7 视图 · / 搜索 · Ctrl+K
```

- 备份/导入/CSV/Excel 移出页脚：数据类进「设置 → 数据」，项目类进顶栏「⋯ 项目工具」。

### 2.2 项目工作区：两层页签

```
[项目名 ⚙]  [任务 | 统计 | 决策 | 档案]   [🔍 搜索] [日报] [周报] [⋯]
            [☰ 列表 | ▦ 看板 | 📅 日历 | ⏱ 时间线]   ← 仅「任务」页显示
里程碑倒计时 / 统计 chips（一行）
[快速添加框 + 工具]
```

- 一级页签 `任务/统计/决策/档案`：项目下的四个「页面」。
- 二级分段控件 `列表/看板/日历/时间线`：任务页内四张面孔，单选互斥。
- 「⋯」弹出项目工具菜单：Excel 导入向导 / 导出 .xlsx 计划表 / 导出 CSV / 导出 Markdown / 项目设置 / 另存为模板。
- 全局模式（今日聚焦/收件箱/智能视图/需求池/会议/干系人/每日笔记）：顶栏只显示标题 + 情境 chips + 主操作，两层页签与 ⋯ 菜单隐藏。

### 2.3 设置弹窗：五节导航

顶部横排节签：`🧭 通用 | 🤝 自动化 | 🖥 桌面集成 | 🤖 AI 供应商 | 💾 数据`

| 节 | 内容 |
|---|---|
| 通用 | 每日收尾问答时间、每日提醒说明（侧栏 ⏰）、数据安全说明 |
| 自动化 | 4 个固定规则开关（逾期置顶/待清理/完成停表/收件箱提醒） |
| 桌面集成 | 开机自启、全局快速捕获热键、今日目标数、深链接说明 |
| AI 供应商 | 供应商卡片 + 预设/模型/地址/Key/拉取模型/测试连接（原样保留） |
| 数据 | 立即备份、导出 JSON、导入 JSON、打开回收站 |

### 2.4 快捷键（修正后与界面顺序一致）

| 键 | 作用 |
|---|---|
| 1/2/3/4 | 列表 / 看板 / 日历 / 时间线（任务页四张面孔） |
| 5/6/7 | 统计 / 决策 / 档案（一级页签直达） |
| N / K / Ctrl+K / / | 新建 / 命令面板 / 搜索 |

### 2.5 视觉系统

- 保留既有 CSS 变量体系（明暗双主题），统一间距/圆角/阴影尺度。
- 新组件：一级页签 `.ptabs`（下划线式）、分段控件 `.seg`（胶囊式）、下拉菜单 `.menu-pop`、设置节签 `.st-tabs`。
- 其余（卡片/看板/日历/甘特/统计/弹窗）渐进精修，不推倒重来。
