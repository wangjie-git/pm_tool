# 增补方案实现说明（v1.4 · 2026-09-06）

> 依据 [PM工具功能调研2-增补方案.md](PM工具功能调研2-增补方案.md) 逐项实现。本文记录每项功能的落地位置与行为，便于验收。
> 技术约束保持不变：原生 JS + SQLite（Tauri 2 Rust 后端），本地优先，无外部依赖服务。

## 第一梯队（全部实现）

### #1 任务计时 → 日报带工时 ✅
- 后端：`time_logs` 表（task_id/project_id/date/minutes）；`start_timer` / `stop_timer` / `get_timer` / `get_time_logs` 命令；计时状态存 meta，重启不丢；停表按开始日期归属，不足 1 分钟记 1 分钟。
- 前端：任务卡「⏱ 计时」按钮；右下角悬浮计时条（任务名 + 实时秒表 + 停止）；进行中卡片显示 ⏱ 徽章。
- 日报新增「四、今日投入」，周报新增「四、本周各项目投入工时」，统计页新增「本周投入工时」横向条形图。

### #2 每日收尾问答 ✅
- 后端：每日提醒线程到 `shutdownTime`（默认 17:30，meta 可改/可关）发系统通知。
- 前端：到点（且当天未答）自动弹出「收尾三问」弹窗，预填今天勾完成的任务；答案存 `shutdown_<日期>`。
- 次日生成日报时：「今天干成什么」并入「昨日完成」（★ 标记），「明天三件事」置顶「今日计划」，卡点附在报告末尾。

### #3 一键推迟到明天 + 拖延徽章 ✅
- 任务卡「⏭ 明天」按钮：due=明天，`defer_count`+1；≥3 次显示红色「⚠ 已推迟 N 次」徽章（提示删/改期/升级）；完成时清零。

### #4 项目模板一键建项 ✅
- 项目设置「💾 另存为模板」：保存未完成任务集（标题/备注/优先级/负责人/循环/清单）到 meta `templates`。
- 新建项目弹窗：名称 + 模板下拉（含删除模板），一键带入任务骨架，截止日默认今天。

### #5 回收站 / 软删除 ✅
- 后端：`deleted_items` 表（task/project 快照 + 删除时间）；`delete_task`/`delete_project` 改为软删除；`list_deleted` / `restore_deleted` / `purge_deleted`；启动时自动清理 30 天前条目；恢复时 id 冲突自动分配新 id（项目连带其全部任务，parent_id 同步重映射）。
- 前端：侧栏 🗑 入口带数量角标；回收站弹窗支持逐条恢复 / 彻底删除 / 清空过期；删除 toast 的「撤销」改为直接从回收站恢复。

### #6 风险登记册升级 ✅
- 任务新增 `risk_prob` / `risk_impact` / `risk_mitigate` / `risk_escalate` 字段；编辑弹窗勾选风险后展开「风险登记册」区（概率 1-5 × 影响 1-5 = 风险值实时显示）。
- 排序：风险值 ≥15（高危）的任务在列表/看板置顶排序并显示红色左边框；卡片风险 chip 显示 R值。
- 跨项目内置智能视图「⚠ 风险登记册」：表格化（项目/风险/概率×影响/风险值/应对措施/升级条件/负责人/截止），按风险值降序，高危行标红。
- 日报/周报风险栏按风险值降序，输出 风险值 + 概率×影响 + 应对 + 升级条件。

### #7 每日三只青蛙（MIT）✅
- meta `frogs`（按日存储，最多 3 只）；任务卡 🐸 按钮标记/移除；今日聚焦顶部固定「🐸 今日三件要事」栏（编号 + 完成 + 移除）；复制今日清单时青蛙置顶并去掉重复项。

### #8 钉钉/企微群机器人推送 ✅
- 项目设置新增「群机器人推送」：类型（企业微信 / 钉钉 / 飞书）+ Webhook 地址 + 钉钉加签密钥。
- 后端 `send_webhook`：ureq 本地 HTTP POST；钉钉自动 HMAC-SHA256 加签（timestamp+sign）。
- 报告弹窗「📤 发到群」：文本超长自动分段（每段 ≤1800 字），解析机器人返回的 errcode 报错。

## 第二梯队（全部实现）

### #9 保存的跨项目智能视图 ✅
- 内置 3 个：⚠ 风险登记册（表格）、⚠ 风险且逾期、⏳ 等待超 3 天；侧栏「智能视图」区可「＋」保存自定义（风险 / 逾期 / 等待≥N天 / 停滞≥N天 / 优先级），复用今日聚焦的分组渲染引擎，可删除自定义视图。

### #10 检查清单进度 roll-up ✅
- 列表 / 看板卡显示进度条（清单+子任务合并完成率）与「☑ x/y 子n」chip；编辑弹窗可选同项目「父任务」，父卡进度自动上卷（GitHub sub-issues 思路）。

### #11 周期统计 cycle time ✅
- 任务首次切「进行中」记录 `doing_since`，完成后计算处理时长；统计页新增「⏱ 周期统计」面板：平均处理时长、未完成逾期率、近 4 周逾期率趋势柱状图。

### #12 收件箱分拣 Triage ✅
- 快速添加工具栏 📥 切换「先进收件箱」（projectId=0）；侧栏「📥 收件箱」入口；收件箱视图逐条选项目「分派 →」/ 推明天 / 删除；每日提醒附带收件箱待分拣数（规则开关控制）。

### #13 固定规则自动化 ✅
- 设置弹窗预置 4 个开关（meta `autoRules`，默认全开）：逾期自动置顶排序（渲染层）、停滞 14 天自动出现「🧹 待清理」视图、完成自动停表、每日提醒附带收件箱数。

### #14 需求池 RICE/四象限 ✅
- `ideas` 表（价值 1-10 / 工时 1-10 / 已转标记）；优先分 = 价值÷工时 排序；四象限（立即做/规划做/顺手做/考虑放弃）；「转任务」选项目 + 截止日一键转换并打标；随 JSON 导入导出。

### #15 循环任务预占日历 ✅
- 日历视图为开启循环的未完成任务绘制后续发生日期的虚线「🔄 预占」块（每周 +7 天 / 每月同日顺推），tooltip 提示到期未完成自动顺延。

### #16 AI 润色日报 · 自定义模型供应商（可选）✅（2026-09-06 改版）
- 原 v1.4 初版只支持本机 Ollama，实际使用受限（未装 Ollama / 本地小模型润色质量不足）即不可用。现参考 ZCode 的「自定义模型供应商」思路改版：**预设供应商 + Base URL + API Key + 模型 ID**，全部统一走 OpenAI 兼容 `/chat/completions` 协议。
- 设置 ⚙ → 「AI 润色 · 自定义模型供应商」：供应商预设下拉（智谱 GLM / DeepSeek / 月之暗面 Kimi / 阿里云百炼 / SiliconFlow / OpenAI / OpenRouter / 本机 Ollama / 自定义，选中自动带出 Base URL 与默认模型），「↻ 拉取模型列表」调用 `GET {BaseURL}/models` 填充候选，「⚡ 测试连接」发一条测试消息验证 Base URL / Key / 模型，密钥支持明文切换；API Key 只存本机 SQLite（meta `aiProvider`），请求由本地 Rust 进程直连供应商，无中间服务。
- 后端命令改为通用 `ai_chat(cfg, system, user)` + `ai_list_models(cfg)`：Ollama 用其自带 OpenAI 兼容端点 `http://localhost:11434/v1`，与云端供应商共用同一协议，无单独适配；HTTP 错误翻译为可排查的中文提示（401 Key 不对 / 404 Base URL 不对 / 429 限流等），自动剥掉模型输出外层的 ``` 围栏。
- 旧设置迁移：老版本 meta `aiModel`（Ollama 模型名）自动映射为「本机 Ollama」预设，老库升级无感。
- 报告弹窗「🤖 AI 润色」行为：未配置供应商时 toast 引导打开设置；润色完成提示所用供应商与模型；浏览器预览模式返回不支持提示。system 提示词由前端按场景传入，便于以后扩展更多 AI 场景（拆任务 / 总结等）。

**AI 提效定位（2026-09-06 交互改版）**：AI 只做两件事——①把「非结构化输入」变成「结构化草稿」（粘贴文字→任务、任务→清单），②优化输出措辞（报告润色）；一律先出草稿、用户确认/可撤销后才生效，不让 AI 直接写数据。已有确定性逻辑的场景刻意不套 AI：排序置顶（规则自动化）、快速添加行内语法（打字流不容忍秒级延迟）、日报数据汇总（数字必须精确，防幻觉）。

- **🤖 AI 粘贴转任务**（快速添加工具栏入口）：会议记录 / 群聊 / 邮件整段粘贴 → AI 拆成任务草稿（标题 / 日期 / 负责人 / 优先级 / ⚠风险 / 备注）→ 弹窗内逐行预览可改可勾选 → 「添加所选」才入库（目标可选收件箱或项目，默认收件箱模式进收件箱）。相对时间（周三/月底）由 AI 按当天日期换算为具体日期。
- **🤖 AI 生成检查清单**（任务编辑弹窗清单区）：按任务标题 / 备注生成 3-6 条可验证步骤草稿，追加进清单编辑器，可改可删后随任务保存，重复条目自动去重。
- **润色可撤销**：AI 润色完成后 toast 带「撤销」按钮，一键还原原文——AI 措辞未必比人写得好，回退零成本。
- **多供应商档案管理（2026-09-06 二次改版）**：设置 ⚙ 的 AI 区块升级为独立卡片——供应商档案列表（绿点 = 启用中）+ 预设 / 模型 / Base URL / Key 编辑区 + 「↻ 拉取模型（结果以可点选 chip 呈现）」「⚡ 测试连接」「＋ 另存供应商」「🗑 删除（按钮二连击确认，因设置弹窗层级高于确认弹窗）」。点卡片即切换并启用；档案数据存 meta `aiProviders`（数组，各家独立保存 Key）+ `aiActiveId`，旧的 `aiProvider` / `aiModel` 自动迁移为首个档案。交互语义：换预设 = 开始填新草稿（已填内容先暂存回所选档案，且 preset 不回写）；另存 = 把当前表单草稿固化为新档案、不回写选中档案；点卡片 = 载入并启用。AI 功能入口（润色 / 粘贴转任务 / 生成清单）统一读取启用档案。
