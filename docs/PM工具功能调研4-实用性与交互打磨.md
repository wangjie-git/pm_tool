# PM 待办助手 · 实用性优化方案（v2 实机走查版，2026-09-06）

> 修订说明：本方案第一版基于代码静态调研（通读 index.html / app.js / styles.css / quick.html）。应用户反馈「用起来还是不顺手」，本版补做了**实机逐屏走查**（运行 v2.1.0 构建，走查了今日聚焦 / 项目列表 / 看板 / 日历 / 时间线 / 统计 / 收件箱 / 任务编辑与新建弹窗 / Ctrl+K / 明暗双主题），把方案从「功能清单」重写为——
> ① 立即可修的毛刺清单（一天内可清完，直接提升专业感）；
> ② 按「日常动线」重组的体验改造（不再按功能点罗列）；
> ③ 功能增补项（沿用第一版已验证的结论，压缩保留）。

### B. 体验结构级结论（走查综合）

1. **首屏「今天要干什么」被淹没**：今日聚焦一屏里，青蛙空槽区 + chips + 灰色说明行 + 4 个状态按钮占了卡片高度的 70%+，一屏只能完整看到 1~2 张任务卡；每张卡 4 个状态按钮 × 每卡重复出现是最大的视觉噪音源。
2. **任务编辑弹窗过长**：带风险的任务弹窗约 890px 高（贴满 979px 窗口），改个截止日期要滚过整块风险登记册；「所属项目」字段缺失（编辑时沿用原 projectId，app.js:2116-2123 已核实）。
3. **内容区「上挤下空」**：顶栏两层页签 + chips 行 + 里程碑提示行 + 快速添加行共吃掉 ~170px，而视图主体（日历/时间线/看板）下半屏是空白——垂直空间分配与使用频率倒挂。
4. 代码调研发现的交互缺口在实机全部复现：无批量、无右键、列表无排序选择器、无键盘行导航、操作后滚动跳顶、统计页无日期范围。
5. **做得好的**（保持别动）：明暗主题整体协调、看板拖拽、甘特拖条改期+导出 PNG、Ctrl+K 面板动词化条目、看板「把卡片拖到这里」占位、空状态文案、确认弹窗与 Esc 逐层关闭。

## 二、优化方案：按四条日常动线重组

> 原 v1 的「包 A/B/C」改为按 PM 一天的真实动线组织，每条动线给目标态与改动点。

### 动线 1 · 早上开工：打开今日聚焦，10 秒内看清「今天干什么」（2~3 天）

| 项 | 目标态 | 改动点 |
|---|---|---|
| 卡片双密度 | 新增「紧凑密度」：单行 = 完成圈 + 标题 + 截止 + 负责人 + 状态色条，操作按钮全部 hover 浮出；默认紧凑、可切舒适 | 抽出 `taskCard(t, {dense})`；设置→通用加密度开关（沿用 meta） |
| 状态按钮降噪 | 紧凑模式下 4 状态按钮改为**状态色条 + 点击循环切换**（或 hover 浮出原按钮组） | 卡片模板 |
| 青蛙区 | 空槽压缩为一行「从下方卡片 hover 点 🐸 选今天三件要事」；已选青蛙显示为三枚横排小卡 | 今日聚焦模板 + A5 |
| 分组收起 | 今日聚焦「进行中 0」「今天到期 0」等空分组不渲染；逾期组置顶保持 | renderToday |
| 首屏高度 | 动线 1 的内容区与动线 3 共用「高度充满」改造（A8） | CSS |

### 动线 2 · 白天处理任务：改状态 / 改期 / 归位，每步少一半点击（4~5 天）

| 项 | 目标态 | 改动点 |
|---|---|---|
| 编辑弹窗分区 | 弹窗折叠为三段：**基本信息**（标题/截止/负责人/优先级/状态/所属项目，默认展开）｜**风险登记册**（勾选⚠才展开）｜**清单与备注**（默认收起为摘要行）；右下保存，标题 Enter 保存、备注 Ctrl+Enter | mw-task 模板 + saveTaskModal；顺手加「所属项目」下拉（换项目，v1 已述）与「保存并新建」 |
| 换项目 | 详情弹窗基本信息段加所属项目下拉 | 0.5 天，v1 A1 保留 |
| 右键菜单 | 卡片右键 = ⋯ 菜单同款（复用动态生成）；侧栏项目右键 = 重命名/归档/另存模板/导出 | 复用 .menu-pop |
| 批量操作 | 列表/今日聚焦/收件箱支持 Ctrl/Shift 多选，浮出批量条：改状态/推明天/删/移到项目（收件箱即批量分拣） | 选中态模型 + 批量 API |
| 键盘流 | ↑↓/J K 移行、空格完成、Enter 详情、X 选中；配合 A1 的 e.code 修复，N/K/1-7 全部 IME 免疫 | keydown 处理器改造 |
| 排序选择器 | 列表页头：智能（现行规则链）/截止日/创建时间/负责人/手动（拖拽写 sortOrder） | 列表渲染 + 拖拽复用看板代码 |
| 滚动保持 | 每次 render 后按容器恢复 scrollTop | render 尾部钩子 |

### 动线 3 · 盯时间承诺：日历 / 时间线 / 统计用得像「驾驶舱」而不是「报表堆」（3~4 天）

| 项 | 目标态 | 改动点 |
|---|---|---|
| 高度充满 | 三视图主体撑满窗口剩余高度（A8），消灭下半屏空白 | CSS/容器 |
| 日历拖拽 | 任务块拖到其他日期=改截止；点空白天新建（预填日期）；「还有 N 项」点开当日浮层 | 复用甘特拖拽吸附代码 |
| 时间线 | 行高随任务数自适应；空白格拖画=新建任务；「＋」建里程碑入口 | SVG 渲染参数 |
| 统计范围 | 页头加范围切换：近 7 天 / 本月 / 近 30 天 / 全部，全部图表共用 | stats 渲染参数化 |
| 统计降噪 | 条形图按比例（A7）；「暂无数据」类卡片（交付预测/SLE/预算）合并为顶部一条引导，不再每卡独占一屏；统计页隐藏快速添加行（A6） | stats 模板 |
| 全局搜索页 | 跨项目搜索任务+决策+会议+干系人+每日笔记，分组结果；命令面板去 14 条上限 | 新结果视图 + palette 参数 |

### 动线 4 · 随手记与分拣：捕获无感、分拣一次一条变一屏一批（2~3 天）

| 项 | 目标态 | 改动点 |
|---|---|---|
| 快速添加收敛 | 输入框 + 项目下拉 + 添加；语法按钮收进「?语法」浮层，🤖/📥 保留并加 tooltip | quick 工具行 |
| AI 分拣建议 | 收件箱顶部「🤖 建议分派」：按标题猜项目一键采纳（无 AI 隐藏） | AI 供应商管道 |
| quick 窗升级 | 回车前实时解析预览 chips；项目选择（记住上次）；主题随应用设置 | quick.html |
| 深链接入口 | 卡片 ⋯ 加「复制任务链接」；日报群推送行动项附 `pm-todo://task/123` | 0.25 天，v1 D3 保留 |

## 三、功能增补（新能力，压缩沿用 v1 结论）

| 优先 | 项 | 要点 | 成本 |
|---|---|---|---|
| ★★★ | 单任务提醒 `remind_at` | 详情弹窗一行；复用每日提醒线程扫描；PM「开会前提醒我」硬需求 | 1 天 |
| ★★★ | 备注图片粘贴/附件 | Ctrl+V 贴截图存 app data，note 内 `![](att:…)` 内联渲染；导出 MD 一并拷出 | 1.5~2 天 |
| ★★☆ | 周报基线快照 | 周报发送时存任务分布 JSON，时间线叠加「上周快照」虚影看计划漂移 | 1 天 |
| ★★☆ | NL 建智能视图 | 「逾期且有风险的 P0」→ 条件组（字段枚举可穷举校验） | 1 天 |
| ★☆☆ | 统计导出整页 PNG | 汇报场景统计页截图发群，复用甘特 SVG 导出路线 | 0.5 天 |

观望（维持 v1 判）：全量 Undo/Redo、任务依赖 blocked 标记（第一轮原判）、日历周视图、侧栏折叠、交互式 Toast。

## 四、实施顺序与验收

**顺序**（合计约 11~14 天，可按包拆版本）：
1. **第 1 步（1~1.5 天）**：A1~A10 毛刺全清——半天到一天，专业感立升，先发一个小版本。
2. **第 2 步（2~3 天）**：动线 1（卡片密度+青蛙+空组）+ 弹窗分区与换项目。
3. **第 3 步（3 天）**：动线 2 其余（批量、右键、键盘流、排序、滚动保持）。
4. **第 4 步（2~3 天）**：动线 3（高度充满、日历拖拽、统计范围与降噪、全局搜索）。
5. **第 5 步（2~3 天）**：动线 4 + 功能增补按反馈排。

**验收标准**（走查可测）：
- 新会话打开今日聚焦，不滚动即可看到全部逾期+今天任务（紧凑密度下 ≥8 张/屏）；
- 20 条收件箱分拣 ≤ 30 次点击（现状约 60）；
- 连续处理 10 个任务（勾完成/改状态）页面不跳顶；
- 中文 IME 开启状态下 N/K/1-7 全部可用；
- 改一个任务截止日期：列表内 ≤2 次点击，弹窗内无需滚动；
- 统计页一屏内可切换「本月」并看清 3 张图，无满宽误导条。
