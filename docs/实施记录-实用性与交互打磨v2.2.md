## 二、四条动线改造

### 动线 1 · 早上开工（今日聚焦 10 秒看清）
- **卡片双密度**：`S.density`（compact 默认 / cozy），设置→通用可切换并持久化。紧凑卡 = 完成圈 + 单行标题 + 右侧 chips（截止/优先级/负责人/风险/⏰提醒/☑进度/🐸/状态循环），操作按钮 hover 浮出；实测一屏 ~15 张（验收 ≥8 ✓）。
- **状态按钮降噪**：紧凑模式 4 按钮收成 1 枚可点击循环的状态色 chip（📥待办→🔨→⏳→✅）。
- **青蛙区**：空槽一行引导；已选青蛙横排小卡。
- **分组收起**：今日聚焦空项目组不渲染（原有）+ 列表空组折叠（A4）。

### 动线 2 · 白天处理任务
- **弹窗三段分区**：基本信息（默认展开，含新增「所属项目」下拉 + 「单次提醒」）｜风险登记册（勾 ⚠ 自动展开）｜清单与备注（默认收起，摘要行显示「清单 n/m · 备注…」）；右下「保存 / 保存并新建」；标题 Enter 保存、备注 Ctrl+Enter 保存。
- **换项目**：编辑弹窗「所属项目」下拉，切换后父任务选项联动重建。
- **右键菜单**：卡片右键 = ⋯ 菜单同款（计时/推迟/要事/置顶/编辑/复制链接/删除）；侧栏项目右键 = 设置/另存模板/Excel/CSV/Markdown 导出（自动先切到该项目）。
- **批量操作**：Ctrl/Cmd+点选、Shift 范围选、键盘 X；底部浮出批量条：✔完成 / 🔨进行中 / ⏭推到明天 / 📂移到项目 / 🗑删除 / 取消。
- **键盘流**：↑↓/J K 移行、空格完成、Enter 详情、X 选中、N 新建、1-7 切视图，全部 e.code 实现 IME 免疫。
- **排序选择器**：列表页头 智能/截止日/创建/负责人/手动；手动模式下按住卡片拖拽排序（全量重排 sortOrder，只写变化的行）。
- **滚动保持**：`renderView` 按上下文（mode+view+项目）恢复 `#content.scrollTop`，同视图内操作不跳顶（实测 400px 滚动位操作后保持 ✓）。

### 动线 3 · 盯时间承诺
- **高度充满**：见 A8；时间线滚动区 `flex:1`。
- **日历拖拽**：任务块拖到其他日期 = 改截止（指针拖拽 + 吸附格高亮，拖后 400ms 点击抑制）；点格空白/＋角标 = 新建并预填日期；「还有 N 项」点开当日浮层（含全部任务 + 「＋新建」）。
- **时间线**：行高自适应；空白格拖画 = 新建任务（预填起止日）；「＋ 里程碑」「＋ 新建任务」入口；「🫥 上周对比」叠加周报基线虚影。
- **统计范围**：页头 近 7 天/本月/近 30 天/全部 全图表共用（KPI、趋势、负载、优先级）；范围持久化。
- **统计降噪**：「暂无数据」类卡片（交付预测/SLE/预算）合并为一条引导面板，有数据的才各占一屏；统计页隐藏快速添加行；条形图固定刻度（A7）。
- **全局搜索页**：搜索框回车进入，跨项目搜 任务+决策+会议+干系人+每日笔记，分组高亮结果；清空自动退出；每日笔记索引由新增 Rust 命令 `list_meta_prefix` 扫描；命令面板关键词结果上限 14 → 60。

### 动线 4 · 随手记与分拣
- **快速添加收敛**：输入框 + 项目下拉（全模式可见，项目视图跟随当前项目）+ ＋添加；语法收进 ？ 面板；📥/🤖 保留 tooltip。
- **AI 分拣建议**：收件箱顶部「🤖 建议分派」汇总 + 每条卡片「🤖 猜：项目名 · 采纳」（按标题 bigram 与项目名/项目已有任务标题重合度，本地规则无需联网）；下拉自动预选建议项目。
- **quick 窗升级**：回车前实时解析预览 chips；项目下拉（记住上次选择）；主题跟随应用设置；窗口高度 76 → 118px。
- **深链接入口**：卡片 ⋯ 菜单「🔗 复制任务链接（pm-todo://）」。
