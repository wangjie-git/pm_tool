# PM 待办助手

> 本地优先的项目管理 / 待办工具，面向需要同时盯多个项目、多项任务的项目经理。

[![Release](https://img.shields.io/github/v/release/wangjie-git/pm_tool?label=%E4%B8%8B%E8%BD%BD)](https://github.com/wangjie-git/pm_tool/releases/latest)

基于 **Tauri 2 + SQLite**，前端为原生 HTML/JS，无任何外部依赖服务，数据 100% 存储在本机。

## 下载安装

到 [Releases](https://github.com/wangjie-git/pm_tool/releases/latest) 页面下载 `PMTodoAssistant_x.x.x_x64-setup.exe`（资产中文名见其 label），双击安装即可（Windows 10/11，安装时自动处理 WebView2 运行时）。

## 功能特性

### v2.0 界面重构

v2.0 对信息架构做了一轮整体重组：全部功能保留、只重排入口，数据模型与后端零改动（方案全文见 [docs/UI重构方案-v2.md](docs/UI重构方案-v2.md)）：

- **侧栏四分组**：今日聚焦 / 收件箱（跨项目驾驶舱与分拣入口）、项目（含已归档折叠）、洞察（智能视图 + 需求池）、记录（会议纪要 / 干系人 / 每日笔记）；页脚只保留 主题 / 提醒 / 回收站 / 设置 4 个高频按钮，数据类与项目类操作移出页脚。
- **项目工作区两层页签**：一级页签「任务 / 统计 / 决策 / 档案」；任务页内再用二级分段控件「列表 / 看板 / 日历 / 时间线」切换任务的四种视图，两类页签不再混排一行。
- **顶栏「⋯ 项目工具」菜单**：Excel 导入向导、导出 .xlsx 计划表、导出 CSV、导出 Markdown、项目设置、另存为模板，统一收拢原先散落在页脚图标和弹窗底部的项目级操作。
- **设置弹窗五节导航**：通用 / 自动化 / 桌面集成 / AI 供应商 / 数据（备份 / JSON 导入导出 / 回收站），替代原来的单长滚动弹窗。
- **快捷键修正**：1-4 切换任务四种视图、5-7 直达统计 / 决策 / 档案，与界面顺序完全一致。

### v2.1 体验优化

- **任务卡更轻**：卡片操作区从每卡 10 个按钮精简为「状态切换 + ⋯」，计时 / 推迟 / 要事 / 置顶 / 删除收进二级菜单（点击 ⋯ 按任务当前状态动态生成）。
- **富空状态**：项目无任务时展示快速添加语法示例（`下周三 联调 @李四 !P0 #风险`）与一键入口；筛选无结果时提供「清除筛选」。
- **改版导览**：首次启动弹 30 秒界面导览（侧栏分组 / 两层页签 / 项目工具 / 设置分节 / 快捷键），任意方式关闭后不再提示。
- **命令面板动词化**：Ctrl+K 新增 ➕ 新建任务 / 🌙 每日收尾问答 / 🌓 切换主题 / ⚙ 打开设置 直达操作。

**任务与项目**

- **多项目管理**：项目归档、项目设置、里程碑、**项目模板一键建项**（另存为模板，新建时带入任务集骨架）
- **今日聚焦**：跨项目汇总今天到期 / 逾期 / 进行中的任务，按项目分组，一键复制今日清单发给团队
- **今日三只青蛙（MIT）**：今日聚焦顶部固定 3 件要事，复制清单时置顶输出（Todoist 吃青蛙方法论）
- **任务计时 → 日报带工时**：任务卡一键开始/停止计时（Super Productivity 思路），日报/周报自动汇总本周各项目投入工时，统计页有工时分布
- **任务视图**：任务页四张面孔——列表（含搜索/筛选）、看板（拖拽，含 WIP 超限提醒）、日历（月历看截止日分布）、时间线（甘特）；统计独立为一级页签（停滞任务 / 周期 / 工时）
- **快速添加语法**：`下周三 闸机联调 @李四 !P0 #风险 #每周`
  - 日期：今天 / 明天 / 后天 / 下周三 / +3天 / 2026-09-14
  - 负责人 `@张三`，优先级 `!P0 !P1 !P2`，标记 `#风险` `#每日` `#每周` `#每月`
- **收件箱分拣**：快速添加可先 📥 进收件箱不分项目，侧栏入口逐条分派（Linear Triage）
- **检查清单进度上卷**：清单完成率即任务进度条；任务可挂父任务，进度自动上卷（GitHub sub-issues）
- **一键推迟 + 拖延徽章**：卡片上「⏭ 明天」推迟，同一任务推迟 ≥3 次亮「⚠ 已推迟 N 次」逼出决策（TickTick snooze）
- **循环任务预占日历**：每周 / 每月循环任务在日历画虚线占位块（Reclaim.ai 简化版）
- **Ctrl+K 命令面板**：跨项目搜项目 / 任务，键盘直达（参考 Linear）

**汇报与沟通**

- **风险登记册**：风险从布尔标记升级为 概率(1-5)×影响(1-5)=风险值，≥15 标红置顶并强制进日报风险栏，附应对措施 / 升级条件，跨项目登记册表格视图（PingCode 风险模板思路）
- **每日收尾问答**：每天 17:30（可配）弹三问：今天干成什么 / 卡在哪 / 明天三件事，次日日报自动引用（Sunsama Daily Shutdown）
- **日报 / 周报一键发群**：项目设置里配企业微信 / 钉钉（支持加签）/ 飞书群机器人 Webhook，报告一键推送到群

**洞察与统计**

- **跨项目智能视图**：内置「风险登记册 / 风险且逾期 / 等待超 3 天」，可保存自定义筛选（Vikunja saved filters）
- **周期统计 Cycle Time**：记录开始 / 完成时间，统计平均处理时长与近 4 周逾期率趋势（Linear / Azure DevOps）
- **需求池 RICE**：想法 / 需求按 价值÷工时 打分排序，四象限决策，一键转为任务（airfocus / Productboard）

**自动化与集成**

- **固定规则自动化**：预置 4 个开关——逾期自动置顶、停滞 14 天进待清理视图、完成自动停表、提醒附带收件箱数量（Trello Butler）
- **AI 提效三件套（可选）**：自定义模型供应商——支持**保存多家供应商档案、点卡片一键切换**（预设智谱 GLM / DeepSeek / Kimi / 阿里云百炼 / SiliconFlow / OpenAI / OpenRouter / 本机 Ollama，或任何 OpenAI 兼容服务），拉取模型列表点击选型、测试连接，各档案独立保存 API Key（仅存本机 SQLite，本地进程直连供应商）；🤖 **粘贴转任务**：会议记录 / 群聊 / 邮件整段粘进来自动拆成任务草稿（日期 / 负责人 / 优先级 / 风险），确认后才入库；🤖 **生成检查清单**：按任务标题拆出可验证步骤草稿；日报 **AI 润色**支持一键撤销。AI 只产草稿，不直接改数据
- **每日定时提醒**：到点系统通知今日到期任务（默认 09:30，左下角 ⏰ 可改）
- **系统集成**：系统托盘常驻、关闭窗口最小化到托盘、启动时通知今日到期任务、窗口状态记忆

**数据安全与体验**

- **回收站 / 软删除**：删除的任务 / 项目进回收站保留 30 天，可恢复（Azure DevOps Recycle Bin）
- **数据安全**：本机 SQLite 存储，启动自动备份（保留最近 30 份），支持 JSON 导入/导出、CSV 导出
- **体验细节**：明暗主题、快捷键（N 新建、1-4 切换任务视图、5-7 直达统计/决策/档案、/ 搜索、Ctrl+K 面板）

## 从源码构建

依赖：Rust（MSVC 工具链）、WebView2（Win10/11 通常已内置）。

```bash
# 安装 Rust（Windows 也可使用本仓库 tools/install-rust.cmd 的便携方案）
rustup default stable

# 安装 Tauri CLI
cargo install tauri-cli

# 开发调试
cargo tauri dev

# 打包 Windows 安装包（NSIS）
cargo tauri build
```

产物位于 `src-tauri/target/release/bundle/nsis/`。

## 发布新版本

本项目配置了 GitHub Actions（[.github/workflows/release.yml](.github/workflows/release.yml)），推送 `v` 开头的标签即自动在 GitHub 服务器上编译并发布 Release：

```bash
# 1. 先把 src-tauri/tauri.conf.json 里的 version 改成新版本号并提交
# 2. 打标签（版本号与 version 一致）
git tag v2.0.0
git push origin v2.0.0
```

也可以在仓库 **Actions** 页面手动触发，版本号自动取自 `tauri.conf.json`。
